# ABSTRACT

## AI-Powered IVF Journey Tracking System

---

### Abstract

Infertility affects 1 in 8 couples globally, with IVF success rates at just 30-40%. This project presents "IVF Journey Tracker," an AI-powered web platform that helps couples throughout their fertility treatment journey using machine learning, OCR document analysis, NLP chatbot, and real-time wellness monitoring.

---

### 1. Key Implemented Features

| Category | Features |
|----------|----------|
| **AI/ML** | IVF Success Prediction (89.8% accuracy), Emotion Detection, Mood Prediction using Genetic Algorithm + XGBoost + LightGBM |
| **Patient** | Wellness Tracking, Document Upload with OCR, IVF Predictor, Medication Reminders, AI Chatbot, Nutrition Guidance, Forum |
| **Doctor** | Patient Management, Cycle Notes, Appointment Scheduling, Messaging |
| **Admin** | User/Clinic Management, Model Retraining, Analytics |

---

### 2. Technology Stack

- **Backend**: Flask + SQLAlchemy
- **Frontend**: Bootstrap 5 + Chart.js
- **ML**: XGBoost, LightGBM, BNN
- **AI**: Gemini/OpenAI API
- **OCR**: Tesseract, pdfminer
